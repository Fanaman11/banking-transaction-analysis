# Banking Transaction Analysis

**Tools:** SQL, Excel, Tableau (in progress)

**Important:** All records are synthetic and created for practice. They do not represent real customers, transactions, or a real financial institution. A large transaction is flagged only for review; it is not labeled as fraud.

## Project Overview
This project analyzes a transaction dataset to explore transaction category performance, monthly activity, transaction statuses, and data quality.

## Business Questions
- Which categories account for the highest completed transaction value?
- How do transaction counts and amounts vary by month?
- What share of records are completed, pending, or reversed?
- Are there duplicate transaction IDs or missing/negative amounts?
- Which high-value transactions might merit manual review?

## Work Completed
- Imported and explored transaction data using SQL.
- Calculated completed transaction value by category.
- Identified Travel as the highest-value category in the current dataset, at $8,666.82.
